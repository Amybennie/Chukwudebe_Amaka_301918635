# CHANGES - what was fixed after testing

**Student:** Amaka Benedicta Chukwudebe (2026/A/MIT/0517)
**Repository:** advanced-database-portfolio (CampusNest)

The original scripts were drafted by the student's AI tool. They were then run
in a Codespaces-like test machine (stock Ubuntu 24.04, PostgreSQL 16 cluster,
MongoDB 8.0, a `codespace` user whose sudo works only as root), every script
was run start to finish, and these problems were fixed. "Tested result" is what
the fixed version did on that test machine. The student's own results come
from running the scripts in their own Codespace.
